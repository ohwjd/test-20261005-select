# Blume und Duft select test

This repository holds the scores and task records of a campaign on [Let's Encode](http://localhost:57674/), where volunteers encode music together.

To take part, please use the [campaign page](http://localhost:57674/test-20261005-select). Please don't edit files or open pull requests here directly: the campaign's automation keeps the scores and task records consistent, and it can only do that for work done through the campaign page.
